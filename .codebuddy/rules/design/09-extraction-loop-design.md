## 一、本案的本质

> **不新建一个游戏模式，而是把"迷宫模式"从"纯救援探索"扩展为"经济撤离循环 + 救援穿插事件"。**

核心扩展：

- **经济循环**作为新主轴：每次下潜都在跑（买装备 → 下水搜刮 → 撤离回岸 → 卖货 → 升级）
- **救援事件**作为支线高潮：偶发触发，**与赚钱无关**，承载叙事与长期解锁

借鉴的他山之石：
- **塔可夫 / 暗区突围**：撤离玩法骨架（带东西回家才算赢）
- **黄金矿工 / 杀戮尖塔 / 以撒**：商店有限随机刷新，玩家在限制下做最优解
- **地铁：离去**：装备整理与负重感

不做的事：
- ❌ 不做 PVP / 联机
- ❌ 不做抽卡 / 开箱（小游戏政策线）
- ❌ 不做"必须救援才能赚钱"的强绑定（毁叙事调性）
- ❌ 不破坏图鉴系统的"知识性"（图鉴免费、不卖钱）
- ❌ 不破坏主线四关与竞技场（本案只动迷宫模式）

## 二、五条顶层设计原则（**审阅时优先确认这一节**）

后续所有子卷的细节都是从这五条推导出来的。如果哪一条你不同意，整个方案的形状会变。

### 原则 1：救援与经济**分轨**，但**共享场地与资源**

- 经济玩法每次下潜都在跑
- 救援作为**叙事事件**偶发触发（首次新地图必触发，之后约 20%）
- 救援**不是赚钱手段**：奖励是"名声 + 装备图纸 + 保险金"，不是"金币奖励"
- 救援可以**随时拒绝**，不掉名声
- 详见 [extraction/05-rescue-integration.md](./extraction/05-rescue-integration.md)

### 原则 2：图鉴是**知识**，物品是**商品**，两套语义严格分离

| 维度 | 图鉴（知识） | 物品（商品） |
|---|---|---|
| 触发 | 手电照到 → 立刻进图鉴 | 走过去按住轮盘 → 进背包 |
| 数量 | 每种只算一次 | 同种可重复拾取 |
| 持久化 | 永久保留，不会丢 | 死了/呛水会损失 |
| 价值 | 探索成就感 | 真金白银 |

### 原则 3：物品的所有属性彼此独立

**这是与上一版草案最大的设计修正**。物品的**价值 / 重量 / 体积 / 稀有度 / 出现概率 / 品相分布**全部解耦，**不互相推导**。

反例：
- ❌ "稀有 → 贵 → 占地方大"（上一版的错误推导）
- ✅ 鲨鱼牙：稀有 / 贵 / 轻 / 小
- ✅ 铁锚：不寻常 / 便宜 / 重 / 大
- ✅ 怀表：稀有 / 贵 / 轻 / 小
- ✅ 玻璃瓶：普通 / 便宜 / 重 / 大

所有数值由 **JSON 配置表**驱动，不写死代码里。详见 [extraction/01-item-attributes-and-config.md](./extraction/01-item-attributes-and-config.md)。

### 原则 4：商店采用**黄金矿工式有限随机刷新**

不做"全面交易行"模式。商店每次只刷出 3~6 个物品，玩家在有限选项下做最优解。

借鉴《黄金矿工》、《杀戮尖塔》、《以撒》的商店机制——**池子是全集，单次曝光是子集**。

详见 [extraction/02-shop-randomization.md](./extraction/02-shop-randomization.md)。

### 原则 5：保底兜底 + 贪婪 vs 怂的张力

- 玩家**任何时候**都能在商店看到 0 金的兜底装备（小氧气瓶、弱电池）
- 玩家**死亡也不损失**金库已存的钱和永久装备
- 玩家死亡的代价只有：本次携带的消耗品 + 本次背包里的战利品
- **核心爽感**：氧气剩 30%，前面有件稀有物，捡不捡？
- 项目现有的氧气阶梯系统、撞岩压强、呼吸浮力，已经把这种压力曲线做得无比细腻——**这是项目最大的隐性资产**

## 八、设计意图陈述

撤离玩法在小游戏品类里是**最强留存机制之一**，但绝大多数撤离游戏都是 PVP + 强焦虑。本案的特殊性：

> **PVE 单人撤离游戏，把"贪婪 vs 怂"的核心爽点保留，但用救援叙事包裹起来——让玩家在赌博的同时仍然觉得自己在做有意义的事。**

雅各布井这个题材本身（真实事件 / 救援者 / 洞穴 / 死亡阴影）天然适合这种设计——它不会因为加了商店就变得轻浮，反而会让"为了救人的钱"和"为了发财的钱"形成有趣的内在冲突。

**温和的、克制的、PVE 的、有叙事的撤离游戏**——这个细分定位市面上几乎没有，是项目可以自己开辟的赛道。
