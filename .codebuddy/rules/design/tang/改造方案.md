## 二、新主线游戏循环

```
┌─── 主菜单（重构）────┐
│ · 继续游戏           │   接最近 nightIndex
│ · 剧情进度           │   重玩任意一晚（沙盒）
│ · 新游戏             │   清存档重开
│ · 设置（含GM入口）    │
└──────┬───────────────┘
       │
       ▼
┌─── 营地（白天）────────────────────────┐
│  state.screen = 'mazeRescue'           │
│  下潜→救援→上岸→结案                    │
│  ★至少完成一次救援尝试 → 启用"回家"按钮 │
└──────┬─────────────────────────────────┘
       │ 玩家点"今天就到这吧"
       ▼
   昼夜过场（黑场 + 风声 3s）
       │
       ▼
┌─── 家（晚上）─────────────────────────┐
│  state.screen = 'home_evening'         │
│  home.phase: arriving                  │
│           → waiting_knock              │
│           → dialogue（女孩对话）        │
│           → free（自由片刻 + 屋内热点）  │
│           → sleeping                   │
└──────┬─────────────────────────────────┘
       │
       ▼
   入睡过场（黑场，可选梦境占位）
       │
       ▼
   nightIndex++
   dayHadAnyDive = false
       │
       ▼
   回到营地（次日）
```

## 三、状态机重构

### 3.1 `state.screen` 新取值

```ts
type Screen =
  | 'menu'              // 主菜单（重构）
  | 'progressSelect'    // 剧情进度选择（替代旧 chapter）
  | 'mazeRescue'        // 白天：洞穴救援（保留并升级为新主线）
  | 'home_evening'      // 晚上：家场景（新增）
  | 'dream'             // 梦境过场（占位，先不实现内容）
```

**废弃**：`play / win / lose / ending / fishArena`。fishArena 数据保留，主菜单不暴露入口。

### 3.2 删除：`state.story`

整块删除。它是旧主线的状态字段，不复用。

但其中两个字段是**全局视觉特效通道**，被迷宫/竞技场/食人鱼系统都在用，必须迁移：
- `state.story.shake` → `state.fx.shake`
- `state.story.redOverlay` → `state.fx.redOverlay`

```ts
state.fx: {
    shake: number;        // 全局屏震强度（自然衰减）
    redOverlay: number;   // 全局红屏遮罩透明度（自然衰减）
}
```

### 3.3 新增：`state.story2`

```ts
state.story2: {
    nightIndex: number;        // 当前晚序号（从 1 开始；0 表示新游戏开局）
    flags: { [key: string]: boolean };  // 剧情 flag
    knownNights: string[];     // 已经历过的对话 sceneId 列表（用于剧情进度选择页）
    girlVisitCount: number;    // 累计她来过几晚
    girlMissedCount: number;   // 决裂后她没来的晚数
    dayHadAnyDive: boolean;    // 当日是否下过水（控制"回家"按钮启用）
}
```

> `state.npc` 整块**保留**（迷宫救援的被困者还在用），但里面 `state` 字段的取值集合精简：
> 旧值 `'follow' | 'wait' | 'enter_tunnel' | 'dead' | 'catch_up' | 'rescue' | 'to_dead_end'` → 新值 `'distress' | 'rescued' | 'inactive'`。
> 这意味着 `Logic.ts` 里那些处理潘子状态机的代码全删。

### 3.4 新增：`state.home`

```ts
state.home: null | {
    phase: 'arriving' | 'waiting_knock' | 'dialogue' | 'free' | 'sleeping';
    timeInPhase: number;       // 帧
    sceneId: string;           // 当夜对话脚本 id
    girlWillCome: boolean;
    dialogue: {
        nodeIndex: number;
        textProgress: number;
        autoAdvanceTimer: number;
    };
    actors: {
        man:  { x: number; y: number; targetX: number; pose: string };
        girl: { x: number; y: number; targetX: number; visible: boolean; pose: string };
    };
    hotspotsClicked: string[];
    sleepBtnVisible: boolean;
}
```

### 3.5 删除：`state.menuScreen` / `state.chapterScrollY`

新菜单/进度选择用各自的局部状态。

### 5.2 DialogueScene 数据结构

见 `剧本-00-总览与角色塑造.md` 的对话设计，与本节定义对齐。简略：

```ts
interface DialogueScene {
    id: string;
    nightIndex: number;
    title: string;             // 用于剧情进度选择页
    girlComes: boolean;
    pre?: SceneAction[];       // 对话前演出（敲门声、女孩入场动画）
    nodes: DialogueNode[];
    post?: SceneAction[];      // 对话后演出（女孩离开）
    onComplete?: { setFlags?: string[]; addStone?: boolean };
}

interface DialogueNode {
    speaker: 'man' | 'girl' | 'narration' | 'silence';
    text?: string;
    duration?: number;         // 不填=等点击
    action?: SceneAction;
    kickOut?: boolean;         // 是否给"该回去了"选项（极少用）
}

type SceneAction =
    | { type: 'wait'; ms: number }
    | { type: 'sfx'; name: string }
    | { type: 'move'; who: 'man' | 'girl'; to: 'door' | 'sofa' | 'desk' | 'window' | 'exit' }
    | { type: 'fade'; to: 'black' | 'in'; ms: number }
    | { type: 'addStone' }
    | { type: 'flag'; key: string };
```

### 5.3 home.phase 推进

```
arriving (3.5s 自动演出)
   └→ waiting_knock (1.5s 等敲门)
        ├→ dialogue（girlWillCome=true）
        │     └→ free（女孩走完之后）
        └→ free（girlWillCome=false）
              └→ sleeping（玩家点睡觉/挂机超时）
                    └→ 黑场 → nightIndex++ → 切回 mazeRescue
```
