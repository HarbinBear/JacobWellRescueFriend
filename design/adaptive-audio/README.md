# Signal Below VI · 发现后的温暖与乐句入口

根据用户最新试听反馈重写：V版主要换音区/音色，和声仍压抑；死亡缺少可听见的duang；第五层下一拍进入仍突兀。VI版改写实际和声、旋律答句和整套有音高伴奏，加入两小节乐句入口与过门，恢复清楚死亡起音。未推进游戏可视化。

2. `undertow/theme-colors.wav`：48s，0:00寻找，0:16发现，0:32返程。
3. `undertow/rescue-journey.wav`：40s，0:00寻找二级，0:08四级，0:14滚奏过门，0:16新乐句的第五级与发现和声，0:24绑好确认与返程。
4. `undertow/death.wav`：6.4s，清楚duang起音后接下坠与暗尾。

下面A/B/C各有三态、救援全过程、四到五层、独立主题与死亡试听。旧V版A主题/死亡/过渡保留在archive-v5。实时播放器显示等待乐句入口的秒数。

## 音乐上的改变

寻找阶段仍为D小调（B为E小调、C为C小调）；发现与返程改写为相对大调F/G/E-flat。A的发现和声为F(add9) → C/E → Bbmaj9 → F/C；B用F(add9) → Am7 → Bbmaj9 → C6（整体移调）；C用F → Bb6/9 → Gm9（省略三音） → F(add9)（整体移调）。保留六/九和弦的空间感，末段有较明确的主和弦落点。

主题开头保留节奏与旋律轮廓，但音级按大调重新写；每个两小节乐句的后半句删去碎音，让第二音延伸、落在和弦音。返程末句落到大调主音。改变不再只是移高八度或换乐器，是否符合用户要求的温暖感仍待主观试听。

低音、信标、琶音与最高密度层也有对应的大调版本，和底轨一起换，避免温暖底轨下面仍叠小调伴奏。鼓组共用。最高层仍为320次/16秒，即每秒20次起音，峰值兴奋感保留。

## 第五层的音乐时机

谱面以两小节为一个问答/和声单元，循环入口是第0/8/16/24拍。人物入镜只是请求，第五层等待下一个两小节乐句开头；120BPM下最多约4.025秒。前一小节排入无固定音高滚奏，最后一拍加密，构成过门；排队不足一小节时只播放结尾一段。转调与第五层在同一入口，整套有音高配器用300ms交接；第五层从原来的任意下一拍改为乐句层面的安排。

过门与切换均由音频时钟排程，逐帧重复请求不重排。预判失效/离开画面撤销未开始的过门与第五层。第一次实际入镜后情绪保留“已发现”，人物暂时出镜只撤高潮，底轨不会退回寻找。绑好时有独立确认音，下一拍进入返程底轨，暖色搜索层1.5秒收束。

人物入镜条件仍是实际镜头位置/摇曳/缩放下身体与视口相交，不要求160px、照明、朝向或遮挡。历史npcFound不授权新下潜的音乐。镜头/NPC速度最多前瞻半秒，预测不是精确像素与输出延迟同步。

## 死亡

3ms起音、中低频撞击主体与短促非整数泛音提供明确duang；其后才是缓慢下坠、迟到的远处共鸣和6.4秒尾音。结算页保留尾音；静音/后台停止。死亡会停止尚未结束的绑绳确认音，避免成功与失败反馈混响。入水仍用原水花音。

## 实现与检查

- AdaptiveScore：小调寻找、大调发现/返程、warm layer tracks、两小节乐句。
- AdaptiveMusicEngine：12条同步循环，整套配器切换、可撤销过门和当前包络接续。
- AdaptiveMusic：按需合成、入镜/预判、情绪保持、返程/死亡。
- AdaptiveCues：死亡duang与暗尾、独立确认音、2秒无音高过门。
