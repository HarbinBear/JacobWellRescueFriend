# Signal Below VII · 清楚和声与低延迟发现

本轮处理实际听感反馈：返程和声太弱、与发现区别不清楚、过门听不出、第五级迟到。VI已提交为99d26b4；VII已获用户认可并授权提交。游戏视觉未改。

打开 listen.html，先听顶部48秒的「寻找→发现→返程」，再对照上次 VI 版。完整救援40秒：0s寻找、8s四级、15.5s短过门、16s发现五级、24s绑好返程。下方「拆开听」提供A/B/C三种状态的和声/旋律/完整底轨，不额外放大独奏；实时播放器可模拟预计0.8秒后入镜。

寻找保留小调悬念，发现保留VI的相对大调改写和主题动机，并非简单升八度。三态底轨新增有清楚起音的中音区和弦与低音，降低旋律相对电平。返程少碎音、低一八度、奇数小节用长答句，末段和声/低音回主和弦。返程和发现仍有主题与和声联系，但不再只换乐器。

第五级优先预计入镜附近的半小节入口，必要时用一拍短过门。500ms滚奏有短击、加密与收束，增益.65；和声300ms交接，第五层140ms展开。实际入镜后的排程等待上限约525ms；预判最多提前120ms展开，取代旧版最多4.025s等待。游戏用相机/NPC相对速度与身体-视口扫掠求最多1.1s的到达时间，每帧修正；实际发现提示仍只看当前帧。恒速预测与排程界限不包含设备输出延迟，也不能保证突发转向/缩放时完全同步。

绑好确认音只短暂让背景降到72%，550ms恢复，返程650ms交接，节奏层1.5s收束。死亡duang与6.4s下坠余音沿用已认可版本，死亡时背景60ms收束避免撞击叠加削波。

三版每套12个16秒24kHz单声道循环，共约18.4MB，短过门48KB；按需生成，换版旧源500ms淡出。游戏不读取开发WAV。新增声部文件 theme-{search,found,return}-{harmony,melody}.wav；真实声部能量与PCM可校验，主观可听性仍需用户试听。

archive-v6 保存上次A的三态/四到五层；archive-v5与更早快照不改。color-v5-v6.wav保留原历史对比，不重建为VII。参考录音只在本地忽略文件中保存，未上传；参考分析只是信号测量，不代表听取/拆轨。
