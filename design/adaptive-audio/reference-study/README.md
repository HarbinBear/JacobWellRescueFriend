# 参考录音与第五轨修订记录

用户提供的录音约 13.673 秒，AAC、48kHz、mono。已使用 macOS afconvert 在本地解码成 `reference-analysis.wav`；未上传到任何外部服务。录音是最终混音，可能含播放扬声器、房间、话筒及编码染色。

当前没有可供模型直接主观听取录音的工具。本记录是客观信号分析，不是“听过以后”的音色鉴定；也没有把完整混音里的某个成分认定为第五条独立轨。修订的目标来自用户明确反馈：第五轨必须夸张、明显地站到前景。

## 数据提供的线索

使用中心段信号、分频带能量与每 5ms 的分频包络，计算 5–40Hz 调制。峰值是信号能量的周期变化，不等于音符起音数，不用它推断源曲 BPM。

| 指标 | 参考录音 | 旧 A 版最高档 | 新 A 版最高档 |
| --- | --- | --- | --- |
| 1.8–6kHz 占 30Hz–10kHz 的能量比例 | 14.53% | 0.70% | 5.22% |
| 高频包络标准差 / 均值 | 0.752 | 0.411 | 0.707 |
| 该频段 5–40Hz 中最强调制峰 | 17.25Hz | 8.03Hz | 20.00Hz |

源曲与本曲不同，也无法消除手机录音染色，因此表中比例不应机械匹配或当作情绪评分。它给出的线索是：参考的中高频脉动比旧版丰富，旧版的快速前景不足。新版本只验证自己有更突出的快速周期变化，是否带来所需激动感仍由用户试听决定。

旧版第五轨 RMS 比其余音轨合计低约 9.07dB；新版在实际五级混音比例下约低 4.79dB。RMS 包含第五轨内的底鼓和帽镲，不能等同于疾奏单独的响度或主观突出度。新版本的主要改进还包括音区分离和起音清晰度。

`analysis-v2.json` 保存旧版测量，`analysis.json` 保存当前测量。脚本 `scripts/analyzeAdaptiveAudio.py` 读取实际 manifest 混音比例，避免拿未平衡的六轨相加代表游戏最高档。

## 本次修订

- 第五轨疾奏升高八度，仍每 50ms 一个起音，每秒 20 个。
- 乐谱 gain 从 0.13 / 0.12 / 0.14 改成 0.34 / 0.34 / 0.36；同时重新做合成包络和音色，不能直接把 gain 倍数称为最终响度倍数。
- 中高次泛音更突出，起音约 0.8ms、衰减更快，尾音更短、延迟更少，避免密集音型糊成背景。
- 五级时底轨 0.72、信标 0.78、低音 0.9、鼓组 1、第四轨 0.55、第五轨 1；只让位，不关闭已有层。
- 前四轨原始 PCM 保持旧版，便于集中判断第五轨与混音安排。

## 听哪里

## 2026-10-18 完整参考补充

本轮另收到「建安一路627号 3.m4a」：52.351秒、48kHz mono AAC。本地解码为 `reference-full.wav`（忽略，不入Git）。`scripts/analyzeAdaptiveReference.py` 输出 `full-analysis.json`，记录每4秒的频段能量比例及相邻2秒窗谱比例变化候选点。

4–8秒的1.8–6kHz比例约2.07%，12–16秒约26.77%，24–28秒约54.22%；仅提示整体频谱随阶段改变，不能将其解释为某条独立轨已经进入，也不能由手机录音比例确定乐器音色。候选点约6.5/14.5/22/29.5/32.5秒等，不是人工听觉标注，不当作精确游戏切轨时间或节拍。

这轮借鉴重点是用户明确提出的“按音乐时机进入”和“高潮对应当前发现”，实现小节入口、一秒展开与独立事件收尾。主旋律/音色仍沿用上一轮A/B/C，效果需用户试听；没有声称已主观听清完整录音。
