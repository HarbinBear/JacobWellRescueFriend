# 厚岩雕刻：独立实验与制作方向

## 为什么换工作重点

2026-10-26，用户确认v1.0.20在手机已能运行，但指出岩边仍是粗直线折线，岩面仍像贴石头花纹，观感没有体积。用户要求制作方自行提出并推进明确优化方向，不是用户提一点才改一点。

现有基线的色图混入大量固定明暗，细部不跟随法线受光；岩块又被粗轮廓整体裁掉。继续调阴影强度或增加纹理细节不能解决根本观感。方向基线是D矿物断面，不代表旧图已经美术合格。

## 自主方向

先形，后体，后材质，最后铺更多洞室。目标是有断裂结构和水蚀变化的连续厚岩，不是浮着的一排石头按钮，也不是一堵贴花纹的墙。

- 大形：保留断冠双岔洞的突出地标；左侧是倾斜长岩带，右侧是悬垂厚岩，中间是深黑空腔。不要每段都用同样大小、高度和结构。
- 轮廓：长弯、局部凹口、短硬断口混合。并非所有真实岩石都不能有直面，也不能把所有边变成统一圆波浪。避免高频随机抖动伪装自然。
- 体积：突出块、低层、厚断面、凹槽共同构成形体。色图不画死主光，动态受光作用在真实造型表面。侧面参与投影轮廓，不再先加厚再被原遮罩裁平。
- 材质：矿物色差和小裂缝只作补充。先在单色材质里把大形做成立，再补有对应表面起伏的中尺度裂缝及少量颗粒。不能用花纹掩盖轮廓和空间问题。
- 空间：深处岩面只在局部出现，保留空洞与遮挡；不要铺成完整的远景后墙。多层空间关系不能只靠整体画暗。

## 已做的独立实验

本目录不覆盖原 `design/cave-room/assets/`、`reference/` 或手机的 `images/cave-rock/`。

离线生成连续雕刻岩壁、倾斜断冠和厚侧面的可见表面数据，四张运行图保持原尺寸。部分造型使用真正前面/侧面三角形并做深度竞争；不从色图亮度猜法线。原矿物配色只取模糊后的色相，归一化固定亮度，再混入克制的中性色材质。

前面与厚侧面的投影共同合并轮廓；实际游戏的碰撞、手电、锚点和绳索使用实验轮廓。局部遮挡从同份深度采样。边缘保留分数覆盖率抗锯齿。

独立预览复用正式 `game.ts`、模拟、HUD、角色、水体手电和原生试跑保存隔离；仅在构建时覆盖实验场景和岩体模块。不是暂停模拟的新美术渲染器。观察按钮仅切换有效视点和手电角度。

运行中仍是单层可见深度烘焙，不是完整实时三维洞穴，也没有实现所有背面、多层自遮挡与移动视角的真实体积视差。不能用“735个面”“有法线”证明美术过关。

## E01自检结论与下一步

程序与几何检查通过不等于优秀观感。当前关闭纹理仍能读出断冠厚面和凹槽，但表面偏光滑、部分转折和局部阴影显得人工，石质感与整体自然节奏不够。本轮只保留为独立实验，不作为正式美术升级替换用户手机已跑通的基线。

下一步按以下顺序推进，不等用户逐项指出问题：

1. 重组织岩段主形与深浅层，让侵蚀凹处和硬断面在同一连续岩体上自然相接，去掉平滑塑料感与孤立硬片。
2. 对突出块/下方岩面建立更明确的多层遮挡，验证侧面和投影轮廓是否一致。若单层烘焙仍不能承载，独立评估多层几何/真实网格成本，不直接把复杂方案推入手机。
3. 单色转灯通过后再补中尺度缝隙、边缘碎裂和颗粒，材质细节必须支持而非代替体积。
4. 用连续游动、多洞室轮廓、铺绳和手机帧预算验收，再分步合入普通地图。保持包体预留、纹理释放和无performance回归。

验收标准是画面：小尺寸能读出形体差异，单色仍有厚度，转灯时前侧面和遮挡关系成立，边缘无锯齿，无重复模板。不按接口或技术名词数量验收。

## 复现

已有提交中的资产直接可预览，无需重新烘焙、Python或联网：

```sh
npm run cave:sculpt:build
npm run cave:sculpt:check
```

生成纯静态实验入口 `node_modules/.cache/cave-sculpt-study/live/game.html`。用工作区静态服务访问，主菜单点击“岩体试跑”。普通 `npm run game:preview` 仍生成原基线。

可选离线再制作，依赖完全隔离在工作区：

```sh
python3 -m venv --system-site-packages node_modules/.cache/cave-sculpt-python
node_modules/.cache/cave-sculpt-python/bin/python -m pip install -r design/cave-room/sculpt/requirements.txt
node_modules/.cache/cave-sculpt-python/bin/python design/cave-room/sculpt/bake.py
node_modules/.cache/cave-sculpt-python/bin/python design/cave-room/sculpt/check.py
npm run cave:sculpt:build
```

本地Chrome实际游戏采样和完整对照页面，静态服务须监听60972：

```sh
npm run game:preview
node design/cave-room/sculpt/capture.cjs baseline
npm run cave:sculpt:build
node design/cave-room/sculpt/capture.cjs sculpt-depth
python3 design/cave-room/sculpt/review.py
```

对照页生成在 `node_modules/.cache/cave-sculpt-study/index.html`。截图、转灯与单色检查是实际游戏，手机GPU及帧率尚未验收。

## 安全边界

普通手机仍为v1.0.20，原岩体运行资源和造型数据未改变。实验资源放在被打包排除的开发目录，不新增手机包体。若后续合入，四图尺寸/解码内存数量不增加；五次近表面采样比旧三次更贵，需真机验证，不能用静态体积变小承诺帧率。


## E02：地质雕刻与版本留存

本轮已继续制作，第一遍细碎起伏过多，单独提交为cave/sculpt-e02-rough；收敛版cave/sculpt-e02减少微起伏，以有限主裂缝、错层与侵蚀凹槽支持大形，加入少量轮廓破口。两版与E01都可独立回退，不覆盖手机v1.0.20。完整档案见 ../VERSIONS.md。

新增geology.py，凹槽是实际深度变化，法线用同一深度在斜投影下的微分生成；check_geology.py在三个分辨率下验证微分、裂缝终止与可重复烘焙。表面仍是单层可见深度，不能宣称完整3D或已解决全部多层遮挡。

资源导出从E02初稿约2.95MiB收敛至约1.18MiB；法线、材质与AO有损量化到每通道64级，法线最大角误差低于1.8度。高度和边缘透明覆盖率保留完整8位，不降尺寸、不硬切半透明边缘。误差报告与上限检查纳入check.py，不能称为无损压缩。

使用npm run cave:versions -- --all，可同时重建四个历史实际游戏入口。npm run cave:versions:check检查每版资源来自其固定提交，并核对无performance时运行和退出释放，不切换工作区。

本轮真实游戏采样标签是sculpt-e02-refined，上一轮sculpt-depth仍保留；python3 design/cave-room/sculpt/progress.py生成node_modules/.cache/cave-forward/index.html，提供旧实验与新实验、转灯和单色对照。该对照缓存不是正式备份，各版源码和资产以Git标签为准。

当前自检：主裂缝与粗糙度比E01明确，但整体断面和侧面仍有人工构造感。继续优化主形、层次与遮挡，不用细节堆叠掩盖大形，不将实验当成手机美术定稿。


## E03：宽断面、磨损侧面与接触层次

先锁住用户本轮认可进步的E02（cave/art-progress-e02），再做三遍独立实验：cave/sculpt-e03-contact、cave/sculpt-e03-masses、cave/sculpt-e03。所有版本源资源完整提交；旧标签不移动，手机版与私人配置不变。

sidewalls.py生成多段真实侧面，fracture_planes.py用独立不等高宽结构面替换容易鼓成光滑块的薄板样条，并混合保留硬断口和局部侵蚀。contact_ao.py从相同可见深度和物理法线离线估计局部遮挡；平斜面不自黑，开放水域不作为遮挡物。遮挡采样的深度与覆盖率使用同一线性权重归一化，避免水域未用深度漏入岩缘。

mesh_clip.py对凹口顶面进行多边形真实裁剪并保持高度和法线插值。当前报告表明旧重心规则在这些块上没有已接受三角面的明显越界，因此不能把所有人为碎折归因于该规则；本轮主要收益仍是宽断面和侧面结构，该裁剪作为完整性防护。四块顶面覆盖面积全部与实际边界一致，无新漏面或越界。

check_structure.py覆盖宽倾面不自动鼓起中心、侧面真实投影、凹口裁剪、水域与倾面遮挡边界。实际游戏完整移动与轮盘铺绳验收通过scripts/checkCaveRockBrowser.js --sculpt执行，普通入口验收保留原路径。几何检查还核对手电、碰撞、锚点、绳段与通路。

本轮仍用四张864x1344运行图，约1.33MiB；相对E02增加约0.15MiB，但全部在手机打包排除目录，当前手机包仍约7.75MiB。新增侧面三角形和12方向接触采样仅在离线烘焙阶段使用，没有增加运行图、运行三角网格或GPU采样次数。法线和材质为有损但误差受控导出，高度与抗锯齿透明覆盖率保留8位。

对照采样标识为sculpt-e03-refined。python3 design/cave-room/sculpt/progress_e03.py生成node_modules/.cache/cave-forward-e03/index.html；旧E02进展页不覆盖。reference-e03保留紧凑实际游戏对照图与范围报告，不把缓存当作备份。

自检仍未美术定稿：宽倾面和破肩更明确，但侧面仍有人工折面，深岩与近景整体衔接、真正多层遮挡需要继续推进。保持单色、转灯和实际移动评审，不拿程序通过冒充优秀观感或真机性能验收。
