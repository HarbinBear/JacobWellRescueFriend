# 潜水员 V01 否定记录 · 2026-11-12

**V01 已被用户明确否定并撤下，不再作为设计基础或美术参考。**

用户认为它像“廉价的欧美的2D手游”，对主角长相和整体风格都不喜欢。这是整体方向不符，不能理解为调色或微调装备后即可继续。

已撤掉静态人物贴片、评审覆盖和专用页面，恢复原人物。旧 `?diver-art` 地址刷新后进入原洞室评审。被否定的图稿和提示词从当前工作树移除，历史版本保留在提交 `bdb880b` 中，避免重复生成相同方向。正式角色此前没有被替换。

用户最初给出 **Playdead《INSIDE》** 并要求更多实例比较。看过下方五款后，再次明确INSIDE最合适：认可它的简洁、留白、2.5D空间关系及整体完成度；认为其余候选没有提供有价值的差异，手绘人物方向又偏离当前三维洞穴。最新决定是深入学习INSIDE的制作方法，不再停留在相近作品列表。不要将此理解为照搬男孩的年龄、长相或衣服。

下一课题是原生三维潜水员在实际洞室中的造型与受光小样，先侧/背面体块和装备轮廓，再扩动作。手绘与三维在技术上可以混合，但这里优先用三维人物统一体积、灯光、遮挡。INSIDE仍依赖原画与人工美术判断，不能以程序建模替代造型设计。[研究与具体制作约束](../inside-study/README.md)。

不要自行决定主角长相，也不要从这次否定推定用户要求某个性别、族裔或国籍。新的潜水员造型尚未认可，不沿 V01 扩多视角、模型或动作。

真实游戏的正常尺寸和近景对照仍是后续验收方式；程序拼人体、静态贴片和二维旋转均不能冒充完成的三维角色。
