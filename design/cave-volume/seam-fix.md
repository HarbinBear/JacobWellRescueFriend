# 近景分块接缝修复 · 2026-11-12

已修复待办中的 seed7391、(7356,5532,z32) 跨块差异。这里不是贴图色差：修复前，上下块在同一节点的原始场分别为 **-2.475277** 和 **9.631897**，一个判断为岩石，另一个判断为水。实际游戏灰模与手电画面都有局部细裂口。

原因在近景 z16/z32 的沉积扫描：一个分块扫描范围内有洞顶，另一个从水中开始，后者把本应由局部条件决定的地面沉积强度跳过；同时又把已经生长出的钟乳石当作地面扫描基底。深层已有独立基底路径，近层还在使用旧条件。

本次仅让所有 z>0 的可见层使用独立的局部沉积强度及原洞壳基底。没有扩大分块扫描范围、全局重算每层、改变光照或遮掉接缝。z=0 仍使用旧切面生成路径；seed7391 完整碰撞场 SHA256 保持 `310079514742aa94b06af840422b006d7388095a1e12f2fc839d587e6e15a00b`。已有鱼、绳、人物和存档的XY轮廓不变。

五个种子（7391、0、1、26110941、4294967295）的完整XY场均与修复前逐字节相同。边界回归覆盖原缺陷、垂直邻域、原点裁切扫描范围和末端不满块：121,830个共享Float32节点、1,852个共享网格顶点/法线与2,600个跨块插值探针一致；包含6,013个近零面节点。用历史代码运行同一测试会实际失败，避免空测。

修复后两个块在指定节点均为 -2.475277。实际游戏同机位观察确认该细裂口消除。桌面前后均加载16块、probe缓存1,290,096字节；单块最大构建约85/87ms，最大子步骤约10/11ms，属于同机不同运行的诊断数据，不是微信真机性能承诺。没有增加常驻采样层数或缓存尺寸。
