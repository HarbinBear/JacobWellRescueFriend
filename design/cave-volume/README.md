# 三维洞腔灰模小样 S01

本目录是独立小样，不接入手机版，不改动现有溶洞（`src/world/Karst*`、`src/render/RenderKarst.ts`）。

## 要验证的事

此前各版溶洞都是先定二维轮廓，再按“离轮廓多远”推高度，最后在一张正对屏幕的平面上算明暗，所以岩石像平放的浮雕。本小样把顺序反过来：

1. 先定约束：一张有岔路、回环、死胡同的路线图，必须能从入口到被救者。
2. 在约束下生成三维洞腔（`generate.js`）：洞室和通道是三维形体，在朝屏幕里面的方向上有自己的进深和起伏，再叠加低频扭曲、溶蚀起伏和岩层。
3. 碰撞轮廓是洞腔在游戏平面（z=0）上的切面，是结果，不是输入。路线上只保底一条身体净空。
4. 洞腔一次性转成三角网格，用透视相机画（`view.js`）。运行时只画网格。

只做灰模。材质、矿物色、多次反射、水体光束都不在范围内。

## 怎么看

用任意静态文件服务打开 `design/cave-volume/index.html`，或直接用浏览器打开该文件。拖动屏幕或用方向键移动潜水员。底部按钮可以换洞、切换透视强度、切换手电或全亮、斜看、显示碰撞轮廓。

`node design/cave-volume/capture.cjs 7` 会用独立无头浏览器截图到 `node_modules/.cache/cave-volume/`（已被 Git 忽略）。

## 已知不足

- 洞壁目前偏光滑，岩层台阶和断裂面不够明显，还不像岩石。
- 手电贴着游戏平面照，直接照亮的面大多侧对镜头，所以小样加了一处没有遮挡的光斑反照，光会漏到隔壁洞腔。
- 路线图是小样自己生成的，没有接游戏里的种子迷宫，也没有接碰撞、绳索、鱼和存档。
- 个别洞室顶部有方块状瑕疵。
- 只在本机桌面浏览器跑过，没有在手机上测过。
