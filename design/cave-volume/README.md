# 三维洞腔灰模小样

本目录是独立小样，不接入手机版，不改动现有溶洞（`src/world/Karst*`、`src/render/RenderKarst.ts`）。S01 保留在标签 `cave/volume-s01`。

## 做法（S02）

1. 先定约束：一串必须走得通的路点，有岔路、回环、死胡同。路点不规定哪里是洞室、哪里是通道。
2. 宽窄由一张空间上连续的“开阔度”决定，开阔处相邻路线并成大厅，其余地方只留窄缝，所以没有“洞室加通道”的固定分工。
3. 洞腔是巨岩之间留出来的空隙：巨、中、小三档圆角岩块一块一块往路线周围放，挡路就整块挪开，再沿朝向路线的斜面劈掉一角，还放不下就不要。离路线远的地方是完整基岩。每块巨岩有自己的岩层方向。
4. 碰撞轮廓是洞腔在游戏平面（z=0）上的切面，是结果，不是输入。路线上只保底一条身体净空，正常情况下巨岩已经让开，保底几乎不改形状。
5. 洞腔一次性转成三角网格，法线优先取巨岩本身的形状，让面是平的、棱是硬的。运行时只画网格，用透视相机和带阴影的三维手电。

只做灰模。材质、矿物色、水体光束都不在范围内。

## 剖面的三种交代方式

游戏平面前面的岩石被剖掉，剖面在真实洞穴里不存在。查看页底部“剖面”按钮可切换：纯黑、贴边受光（只在洞壁边缘留一圈被手电照到的亮边）、暗岩纹（整块剖面压暗，带一点岩层纹理）。

## 怎么看

用任意静态文件服务打开 `design/cave-volume/index.html`，或直接用浏览器打开该文件。拖动屏幕或用方向键移动潜水员。

`node design/cave-volume/capture.cjs 7` 会用独立无头浏览器截图到 `node_modules/.cache/cave-volume/`（已被 Git 忽略）。

## 已知不足

- 巨岩在全亮下能看出来，在手电下仍然偏碎、偏软，单块巨岩的大面还不够大、不够完整。
- 洞壁贴着游戏平面时，手电照到的面大多侧对镜头，靠一处没有遮挡的光斑反照补光，光会漏到隔壁洞腔。
- 网格分辨率 12 单位，岩层台阶和硬棱靠法线表现，轮廓上还会出现锯齿和小方块瑕疵。
- 生成一次约 0.6 到 0.8 秒，比 S01 慢一倍，进入章节时可以接受，但需要放到后台线程。
- 路线没有接游戏里的种子迷宫，碰撞、绳索、鱼、存档都没接，只在本机桌面浏览器跑过。
