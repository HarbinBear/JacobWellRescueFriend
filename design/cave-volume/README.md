# 三维洞腔灰模小样

本目录是独立小样，不接入手机版，不改动现有溶洞（`src/world/Karst*`、`src/render/RenderKarst.ts`）。S01、S02 保留在标签 `cave/volume-s01`、`cave/volume-s02`。

## 做法（S03）

1. 先定约束：一串必须走得通的路点，有岔路、回环、死胡同，最上面接一个水面入口。路点不规定哪里是洞室、哪里是通道。
2. 溶蚀洞腔：沿路线的一串粗细不均的三维胶囊体，宽窄由一张空间上连续的“开阔度”决定，开阔处相邻路线并成大厅。另有几条从洞里拐到后面去的支洞，只提供纵深，不能进入。
3. 钟乳石体系：在水平面上撒落点，每个落点上面挂石钟乳、下面长石笋，长到一起就是石柱，一部分落点沿裂隙拉长成石幔。它们直接改写洞顶和洞底的形状，相邻形体互相并在一起，不是单独摆上去的物件。洞壁另有竖向拉长的鼓包。路线正中间留出身位。
4. 水上水下：地面和水下洞腔是同一个场。水潭一侧是走得下去的缓坡，另一侧是陡岸，水潭靠后的部分在岩顶下面。
5. 碰撞轮廓是洞腔在游戏平面（z=0）上的切面，是结果，不是输入。最后在路线上保底一条身体净空。
6. 洞腔一次性转成三角网格，运行时只画网格，用透视相机和带阴影的三维手电。

只做灰模。材质、矿物色、水体光束、剖面的最终处理都不在范围内。查看页里的天空、水面和天光只是示意，天光没有算遮挡。

## 怎么看

用任意静态文件服务打开 `design/cave-volume/index.html`，或直接用浏览器打开该文件。拖动屏幕或用方向键移动潜水员，潜水员只能在水面以下活动。

`node design/cave-volume/capture.cjs 7` 会用独立无头浏览器截图到 `node_modules/.cache/cave-volume/`（已被 Git 忽略）。

## 已知不足

- 钟乳石只有“挂下来”和“长上去”两种，没有横向的流石台、石盾、边石坝；洞壁上的鼓包很弱，几乎看不出龟壳感。
- 保底净空在个别种子里会削掉挡路的钟乳石，留下不自然的切口（40 个种子里最多改动 111 格）。
- 洞外偶尔有孤立的小空腔，从某些角度能看到漂在外面的碎片。
- 网格约 11 到 14 万三角面，比 S02 多；生成约 0.25 到 0.4 秒。只在本机桌面浏览器跑过。
- 路线没有接游戏里的种子迷宫，岸上不能行走，碰撞、绳索、鱼、存档都没接。
