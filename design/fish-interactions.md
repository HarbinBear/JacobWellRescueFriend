# 洞潜生物：顶撞与鱼群

普通遭遇中的激怒鱼替换为虚构生物「盾首鳗」，让引鱼入网有反复尝试的余地。猎鲨保留为 GM 可生成的危险挑战。

| 生物 | 外形与动作 | 可以利用的互动 |
| --- | --- | --- |
| 盾首鳗 | 浅色钝头骨盾、青绿长鳍；卷身示警后伸展开冲撞 | 持续照射或近处快速游动可以引起冲撞；蓄力后段锁定方向，可以侧身避开，或把冲撞路线引进网 |
| 银鳞鱼群 | 细长银色小鱼，个体摆尾与转向不同步 | 灯光或快速接近使整群惊散；缓慢接近允许更近距离，安静后重新聚拢。可从一侧驱赶进网 |
| 好奇鱼 | 圆胖、慢游、停下观察 | 跟随灯光和受光岩面 |
| 食人鱼 | 小型暗色捕食鱼 | 用光驱赶，保留原有捕食行为 |
| 猎鲨 | 宽肩流线体、大背鳍、月牙尾与齿列 | 持续照射激怒，保留危险的扑咬；需要利用绳网隔开攻击路线 |

盾首鳗连续受扰约 0.3 秒后开始约 0.63 秒的蓄力，蓄力后段停止追踪玩家。冲撞使用鱼头的扫掠检测，向玩家施加速度冲量，鳗鱼同时回弹。玩家可以继续转向和游动；水阻让这次冲量逐渐消散。反馈包括小范围气泡、水压弧线、身体偏摆与轻微震动。顶撞本身不触发撕咬、死亡或直接扣氧，环境碰撞仍按原有规则处理。约一秒的玩家保护时间避免多条鱼连续叠加冲量。

顶撞或冲空后，鳗鱼先回弹，再在玩家附近恢复约 1.6 秒。停止照射可以利用这段间隙换位、补网；持续挑衅可引出下一次冲撞。普通近身时鳗鱼会回避。

新物种沿用多绳逐步缠绕：盾首鳗需要至少四条独立绳，银鳞小鱼需要至少三条，均需进入交织区域并挂住不同方向的绳段。速度影响网的拉伸，缠绕积累按物种调整。稀疏交叉仍能穿过。鱼群按个体入网，未被缠住的成员继续游动；画外提示每群只显示一个群体图标。

鱼群默认七条，单次生成最多十二条；每帧共享群体感知和中心计算，个体只检查本群邻居。美术使用 Canvas 路径，无新增贴图。真机帧率仍需微信设备验证。

验证入口：GM「迷宫鱼」中生成盾首鳗、银鳞鱼群与猎鲨；`npm run cave:check` 包含无致命顶撞、冲量保护、近处恢复、游动感知、鱼群重聚和五类鱼的密网/稀网回归。
