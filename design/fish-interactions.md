# 洞潜生物：顶撞、鱼群与绑缚

普通遭遇中的激怒鱼替换为虚构生物「盾首鳗」，让引鱼入网有反复尝试的余地。猎鲨保留为 GM 可生成的危险挑战。

| 生物 | 外形与动作 | 可以利用的互动 |
| --- | --- | --- |
| 盾首鳗 | 浅色钝头骨盾、青绿长鳍；卷身示警后伸展开冲撞 | 持续照射或近处快速游动可以引起冲撞；蓄力后段锁定方向，可以侧身避开，或把冲撞路线引进网 |
| 银鳞鱼群 | 细长银色小鱼，个体摆尾与转向不同步 | 灯光或快速接近使整群惊散；缓慢接近允许更近距离，安静后重新聚拢。可从一侧驱赶进网 |
| 好奇鱼 | 圆胖、慢游、停下观察 | 跟随灯光和受光岩面 |
| 食人鱼 | 小型暗色捕食鱼 | 用光驱赶，保留原有捕食行为 |
| 猎鲨 | 宽肩流线体、大背鳍、月牙尾与齿列 | 持续照射激怒，保留危险的扑咬；需要利用绳网隔开攻击路线 |

盾首鳗连续受扰约 0.3 秒后开始约 0.63 秒的蓄力，蓄力后段停止追踪玩家。冲撞使用鱼头扫掠检测，向玩家施加速度冲量，鳗鱼同时回弹。普通冲量由水阻消散；强烈顶撞让玩家短暂撞晕约 0.57 秒并取消正在进行的手上动作，随后恢复控制。反馈包括小范围气泡、水压弧、身体偏摆和轻微震动。顶撞不新增撕咬、死亡或直接扣氧分支，环境碰撞仍按原规则处理。约一秒的保护避免多鱼连续叠加冲量。

顶撞或冲空后，鳗鱼先回弹，再在玩家附近恢复约 1.6 秒。停止照射可利用间隙换位、补网；持续挑衅可引出下一次冲撞。普通近身时鱼主动保持距离，冲撞、捕网、眩晕和绑缚使用独立状态。

物种沿用多绳逐步缠绕：盾首鳗需要至少四条独立绳，银鳞小鱼至少三条，均需进入交织区域并挂住不同方向的绳段。速度影响网的拉伸，缠绕积累按物种调整；稀疏交叉仍能穿过。鱼群按个体入网，未缠住的成员继续游动；画外提示每群只显示一个群体图标。

鱼群默认七条，单次生成最多十二条；共享群体感知和中心计算，个体只检查本群邻居。美术使用 Canvas 路径，无新增贴图。真机帧率仍需微信设备验证。

## 2026-11-08：第二版方向交互

原「主动预选动作 + 绳盘统一动画 + 外侧自己绳端」框架保留，但两套工具都改为只选方向。拖动半径不再选择长度或目标深度；固定范围内通过方向碰撞选择先碰到的对象。

鱼优先于前方绳网，岩石仍挡住鱼，不能越过前面的另一条鱼。绳盘只会绑眩晕或已绑的鱼；动作盘能敲击任何实际能碰到的鱼，不再以已晕或已入网为前提。正常鱼会保持距离，所以多数遭遇仍需诱网。

人物先实际短距离靠近，再完成绕绳、交叉穿结和双手拉紧。对可轻触穿行的网，接近使用原有低速 glide 碰撞规则；反弹、缠住和岩石阻挡仍会取消，不靠隔空完成或位置跳跃。

## 整网拆除

采用用户随后允许的整张连通网移除方案，不强行整理失去支撑的残网。

命中独立绳就取下完整端到端绳；命中打结的网则移除同一连通网。预览高亮全部将被取下的绳，以及依赖这张网作为锚点的牵引连接。其他独立网、独立绳、鱼身绑缚和不依赖此网的连接原样保留。

被拆的网立即退出碰撞和受力，视觉快照约 0.9 秒下沉淡出，不留下小缺口、永久松绳、悬空断头或无支撑节点。腰绳可单根解开并取下，鱼身绑缚不会因此解除。

## 明确动作与力量感

绑绳包含取绳、绕两圈、交叉穿结和双手拉紧。解绳包含扶结、挑开绳环和明显抽出绳尾，手部轨迹、弯肘和身体重心均不同。

敲晕使用短气瓶举起收肘、身体后仰、约 0.07 秒猛砸、回弹收瓶。剪绳使用绷绳蓄力、约 0.07 秒猛然合剪、弹回收手。两者都在瞬时输出帧结算，加入短促重音、强震屏、水压弧和约 50 毫秒局部顿挫，不暂停全场，不在后摇重复结算。

提示文字移到屏幕上沿，不再用浮字或进度圈遮挡人物动作。鱼仅暂时眩晕，约八秒后恢复；绑好则挣扎并传递拉力，没绑则恢复自由行为，不会被敲击杀死。

完整操作和实现边界见 [鱼交互第二版说明](fish-handling/README.md)。第一版距离选择和局部剪口试玩保留在 `fish-handling/v1-distance/`，不作为当前规则。

验证入口：`npm run fish:check` 检查方向、优先级、活鱼命中、冲击帧、整网拆除与结构保持；`npm run fish:preview` 构建实际试玩；`npm run fish:browser` 逐帧验收原生触控与动作。`npm run cave:check` 保留原有岩体、鱼网、恢复和群体行为回归。
