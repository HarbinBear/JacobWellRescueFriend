# 鱼交互：精确动作与统一绑绳

## 试跑

执行 `npm run fish:preview`，在浏览器打开本目录的 `game.html`。这是实际游戏源码的独立浏览器运行包，不替换此前的洞穴或音轨评审包。

页面旁边的「布置诱捕场景」「近身练习：已入网」和位置调整按钮只供此评审页面布置场景；它们不是游戏内的新按钮。试玩使用真实多绳捕网、岩体碰撞、主循环、触控和绳索逻辑，模拟不会暂停。

小游戏内直接在迷宫遭遇鱼，或通过原有 GM「迷宫鱼」生成测试生物。没有新增贴图或音频，敲晕复用已有本地绳轮敲击音。

## 两个入口

| 入口 | 输入 | 预览 | 松手后的操作 |
| --- | --- | --- | --- |
| 新「动作」按钮 | 按住拖动，用方向和距离选目标 | 鱼头准星、被选鱼轮廓、具体绳端或待割局部 | 靠近到可接触位置，执行敲击、解扣或割线动画 |
| 原绳盘 | 按住拖动，选鱼、岩壁、旧绳或绳结 | 实际绑结点和起点/终点名称 | 短距离接近，绕绳、穿结、拉紧后提交连接 |
| 绳盘外侧「自己」 | 已起一端后，把光标拖入小圆 | 腰扣与当前绳一起高亮 | 播放系腰扣动画，再建立随身连接 |
| 动作盘外侧腰绳 | 把光标拖入对应小圆 | 所选整条绳及其另一端一起高亮 | 只解下这一根，鱼身上的绑绳和另一端保留 |

动作按钮短按也先显示正前方鱼头预览，再于松手后下达敲击。短按不会自动剪掉正前方的网，也不会自动解掉腰绳。要操作绳子，必须明确拖动预选。

同一位置有多根绳端时，每根绳在自己的分支方向有小选点手柄，可以分别选择。准星和动画仍落在真正的绳结位置，而非手柄位置。

## 鱼的完整流程

1. 用灯光、游动或冲撞路线引鱼进入已有绳网。普通游动状态会主动保持距离。
2. 靠近后用「动作」预选鱼头，松手下达敲晕。人物扶稳已入网的鱼再敲击，鱼不会被打死。
3. 眩晕时用绳盘选鱼起绳，人物在鱼旁完成绑缚动画。连接并非瞬间完成。
4. 再用绳盘选岩石、旧绳，或拖向外侧「自己」，把另一端连接好。
5. 如果鱼仍被原网兜住，选鱼旁「割缠网」目标。预览明确标出将被割开的每一处，只打开缠住这条鱼的局部，保留绑鱼绳和网的其他区域。
6. 拖走，或留在固定锚点旁。鱼约八秒后会醒来，已绑则挣扎并通过绳子传递拉力，未绑则恢复自由行为。

绑缚和固定不是同一件事：绑鱼后没有连接锚点时，鱼仍可能随水漂动或缓慢挣扎。只有连到玩家、岩石或旧绳之后才受牵引绳长约束。

## 精确操作与取消

预览没有副作用。松手保存所选对象的身份，目标移除、游离操作位置或变更绳源时取消，不会自动换成旁边的鱼或另一根绳。

移动回盘中心再松手取消预选。正在铺设但尚未完成的绳，可在原绳盘中心持续按住约 0.65 秒撤回；这不等于解开已绑好的腰绳。

动画过程中，重新游动或点原有工具位置的「取消」即可中断。不能安全接近、失去接触、鱼苏醒离开、强烈顶撞、窗口失焦、进入后台或其他界面抢占时，同样不会留下半完成的新连接。

割绳预览与真实绳路径一致。普通割网线只删除所选位置附近约 20 像素的局部；割缠网则按鱼的碰撞体型留足缺口，预览明确显示这个范围，避免免网期结束后原地再次挂住。两者都保留两侧绳段；解绳结只解除所选的一端。剪开后绳端明确标为松绳端，不再作为固定岩石锚点，存档保留这一差别。

## 视觉与时长

敲晕使用手持小绳轮的后撤与敲击，伴随局部水压、小星星、闭眼和眩晕倒计时，不使用血迹、死亡淡出或尸体翻白。

绑鱼显示两圈身体绳带和可选择的连接结。岩石、旧绳、鱼和腰扣共用接近与双手工作节奏；系好之前只显示绕绳过程，拉紧的完成时刻才建立连接。

初始时长：敲晕约 0.3 秒；绑鱼约 1.2 秒；绑岩壁/旧绳约 0.83 秒；系自己约 0.6 秒；解扣约 0.53 秒；割线约 0.4 秒。动画和鱼眩晕按实际时间更新，已覆盖 30/60/120Hz 差异。强烈顶撞约 0.57 秒短暂撞晕玩家，不新增死亡或直接扣氧分支。

## 验证与边界

`npm run fish:check` 覆盖五类鱼、预览无副作用、对象身份锁定、系统取消、真实时间眩晕、动画后提交、鱼接自己/岩石/旧绳、独立捕网保持、局部割线、同位绳结分支、解一根腰绳、断绳端存档以及牵引稳定性。

`npm run fish:browser` 通过实际游戏和原生触控输入验收。截图和报告写入 `node_modules/.cache/fish-interactions-browser/`，不进入小游戏包。

鱼、鱼身上的绑缚、临时牵引绳和动作任务是当次下潜运行态；重新下潜会清理，不把瞬间鱼状态存进旧案件档。静态地图绳、绳结与剪开后的松绳端仍按既有存档流程保存。

既有 NPC 救援流程没有改成这套鱼交互。微信开发者工具编译包大小和手机上的动画、操作舒适度及帧率仍需真机验收。
