# 鱼交互第二版：方向、整网拆除与力量感

## 当前规则

绳盘和「动作」盘都只选择方向。拖动超过中心取消区以后，拖近或拖远不会选择不同距离；系统在固定操作范围内做方向碰撞，选择首先接触的目标。

鱼是比绳线更重要的交互实体。方向命中鱼时，优先处理鱼，即使鱼前面有兜住它的绳网；岩石仍阻挡射线，也不能越过前面的另一条鱼。方向没有碰到对象就不会选中，不靠猜测最近点。

普通未晕的鱼也能被敲晕，唯一要求是实际能接触并命中。正常鱼仍会主动保持距离，所以多数情况下需要诱入网来取得接近窗口。鱼只能在眩晕或已经绑缚时被绳盘选为绑绳目标；未晕鱼会挡住该方向，系统不会偷偷改绑它后面的网。

## 两套操作

| 入口 | 操作 | 结果 |
| --- | --- | --- |
| 原绳盘 | 按住，拖向一个方向，松手 | 短距离接近首先命中的鱼、岩壁、旧绳或绳结，再绕绳、穿结、拉紧 |
| 新「动作」盘 | 按住，拖向一个方向，松手 | 对预览明确选中的鱼敲击，或对明确选中的绳结/绳组执行解除和拆除 |
| 绳盘外侧「自己」 | 已起一端后拖入小圆 | 低头在腰扣位置穿绳、拉紧，连接到自己 |
| 动作盘外侧腰绳 | 拖入对应的小圆 | 解开并取下预选的一根牵引绳，保留鱼身绑缚和其他独立连接 |

动作按钮短按同样先出现正前方鱼的预览，松手只启动动作，不会立即把鱼设为眩晕。短按不会自动拆网或解腰绳。

移回中心再松手取消预选。已有起点但还没有完成终点的绳，可在原绳盘中心持续按住约 0.65 秒撤回。

前摇、接近和绑绳过程中，重新游动、点工具上的「取消」、失去接触、撞晕、失焦或界面抢占会安全取消。出手已经命中后的效果不会因为取消后摇而被倒转。

## 拆绳范围

采用用户允许的“整张连通网拆除”方案，不强行把残网重新整理或拉向岩壁。

命中独立绳时，拆下它的完整一端到另一端；命中相互打结的绳网时，拆下与它连通的整张网。其他独立绳、独立网、鱼身绑缚及不依赖这张网的牵引绳保持原样，继续由原本的锚点和物理状态支撑。

预览高亮所有会被移除的绳。若一根牵引绳的锚点就在待拆的网中，它也在预览中一起高亮并随网取下，不会留下悬空的端点。鱼身上的绑绳不因拆网而解除。

整网在动作的合剪命中帧退出碰撞和受力计算；视觉快照继续短暂下沉并淡出，约 0.9 秒后消失。视觉快照不是新的物理绳，不参与捕网或存档，不会永久悬浮、乱飘，也不会把原来拉直的绳子中间挖空几厘米。

## 动作与力量感

绑绳：从腰侧取绳，一手扶住目标，另一手绕两圈；随后双手交叉穿结，再向两侧拉开收紧。鱼、岩壁、旧绳和腰扣使用相同操作语义，但手的位置随真实目标变化。

解绳：先扶住绳结，再挑开绳环，最后明显抽出绳尾并收手。不是与绑绳相同的双手前伸。

敲晕：举起短气瓶，明显收肘和身体后仰；出手阶段约 0.07 秒，猛然砸下；命中后气瓶和身体回弹收回。约 0.05 秒局部顿挫、短促重音、强震屏和局部水压弧强调冲击，不暂停全场模拟。鱼在真正命中时才进入暂时眩晕，不等整段后摇播完。

剪绳：先取剪并用另一只手绷住绳，约 0.07 秒猛然合剪，然后弹回收手。整网拆除在合剪这一瞬间生效，伴随短促重音、震屏、水压和局部顿挫，后摇不会重复移除。

所有动作使用可见的弯肘、手腕、工具和身体重心变化。操作文字集中在屏幕上沿，动作位置不再盖浮字或进度圈。鱼的眩晕小星星仍保留，操作期间不显示盖在手边的倒计时文字。

鱼约八秒后恢复。绑好则继续挣扎并通过牵引绳传递拉力；没绑则恢复自由行为。鱼不会因玩家敲击而死亡。

## 试跑与回归

`npm run fish:preview` 构建本目录的实际游戏试玩。页面侧边的场景布置与移位按钮仅用于评审，不是游戏内的新操作。游戏中的入口仍是原绳盘和新的「动作」按钮。

`npm run fish:check` 检查方向首次碰撞、不同拖动半径一致、鱼优先与岩石遮挡、五类活鱼和入网鱼、真实时间眩晕、冲击帧、局部顿挫、后摇、整网删除、独立网保留、依赖连接、存档、取消和动作差异。

`npm run fish:browser` 使用真实主循环、真实岩体和原生触控逐帧验收。截图与报告写到 `node_modules/.cache/fish-interactions-browser-v2/`，不进入小游戏包。

第一版的方向加距离、局部剪口方案保留在 `v1-distance/`，只作为旧版回看，不是当前规则。当前代码与试玩均已改为本文件描述的第二版。

微信开发者工具正式编译包大小、真机帧率、手机上的触控舒适度和主观打击感仍需真机确认。既有 NPC 救援流程未在本轮扩展为鱼交互。
