# 手机版修复与休闲营地 v1.0.22

本轮直接修改正式 game.ts 使用的 src/world/continuous，不另做替代玩法 demo。上一版 world/mobile-gameplay-v1.0.21 与历版岩体标签保留；本轮回退点为 world/mobile-gameplay-v1.0.22。

## 镜头回归

连续世界的 cameraStep 绕过了旧 CameraLogic，把横屏/竖屏视野固定为 0.76/0.82，并按输入方向立即前瞻 58 像素；入场还额外偏移 90/35 像素。这是人物变小、刚开始移动镜头就偏的原因。

普通玩法恢复同一套 updateCameraSpringArm 与自适应缩放，保留旧跟随刚度、阻尼、35 像素最大速度前瞻和 0.02 缩放平滑系数。岸上只关闭水中摇曳，人物尺寸不改。自适应射线补查实际岸坡和天然边界，深洞沿用原圆岩检测。只有明确打开验收总览才拉远镜头。

## 未完成绳索

旧状态机本身会在终点落空、动作被移动中断时保留原起点；实际误提交来自方向拖动经过绳盘外侧的「自己」腰扣，松手即把未完成绳结算成人体牵引。下一次操作因而变成新绳的起点。

腰扣现在须原地停留约 350 毫秒明确确认，有圆环反馈；滑过、继续拖动或确认时仍有主动移动输入不会提交。自然浮力漂移不当作移动操作，避免人在水下无法正常系腰扣。原「系到自己」玩法保留。未完成绳按钮标为「接终点」，不再用易误解的「收绳」。中心长按撤回仍保留。

新增测试先在旧代码中复现误挂，再验证终点落空、移动中断、重新完成同一根岩壁绳、误滑腰扣、显式腰扣确认与确认时移动六类行为。

## 岸上休闲区

复用现有帆布医疗帐篷，增加帆布遮棚、两张有竹节和绑扎细节的竹躺椅、编织地垫、竹茶桌、茶壶杯子和手编篮子。不新增图片或替换母版，避免扩大解码内存和资源包。

新章节出生点与水下死亡后的恢复点位于休闲区。靠近主躺椅后点击「躺下晒太阳」可实际躺下；点击「起身继续探索」或移动可起身。休息时恢复体力，休息状态可以随原位置保存与恢复。带着腰扣牵引或救援牵引时不允许躺下，避免把对象拉上家具。

左侧以根系盘绕的巨石和树干拦住步行，右侧以林下岩坎阻隔。可见轮廓与身体碰撞、交互射线、绳索路径共用相同多边形；不是只画树后用空气墙拦人。最外层数值边界仍作离图兜底，正常步行先接触天然岩体。

## 死亡返回

气量耗尽与鱼咬死亡过场结束都会自动返回岸上恢复点，不再弹出「重新开始测试章节」，也不清空章节。

保留地图种子、探索、背包、已发现物件、固定绳网及鱼/被救者实体位置。只清除未完成铺绳、解除死亡玩家的腰扣与救援牵引，重置其移动、眩晕、气量和身体恢复状态。鱼与被救者不随玩家传送，仍可重新下水寻找。已完成的章节交接保持完成。恢复后立即保存。

同版已有存档 key 和 layoutVersion 保持兼容，继续章节仍从原位置进入；想查看新出生点可走回休闲区，不必清档。旧的测试档与夜间少女剧情档不迁移。
