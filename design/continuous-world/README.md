# 林泉营地：连续章节 M1

本轮提供真实游戏代码支撑的独立可玩实验，验收“行走 → 涉水 → 游泳 → 拖鱼上岸 → 原位续接”。不是纯概念图，也不是正式版已全部革新完毕。

正式 game.ts、src、原有图片和手机配置均不替换。原版保留在 `world/shore-before-20261109`；本轮 M1 使用独立提交与命名标签保留。

## 设计与边界

完整地图、动画、渲染、存档与阶段计划见 [proposal.md](proposal.md)。

游戏里没有入水按钮、快速回岸按钮或每次出水结算。岸上地图、补气与救援必须实际走到实体旁边交互。商业、资源转化、失败恢复、正式旧档迁移、跨章节迁移和多人联机留到后续节点。

这仍是第一空间与交互验收，不是最终角色、岩体或生态美术定稿。新的生态纹理与动画资产尚未替换，鱼与潜水员沿用当前游戏绘制基础。

## 当前工作版本

在项目根目录运行：

```bash
npm run world:preview
```

输出为已被 Git 忽略的 `node_modules/.cache/continuous-world/game.html` 和同目录运行脚本。使用当前项目 HTTP 预览服务的端口 `60972` 访问该入口。

素材已经烘焙完成，正常试玩不需要重新生成。仅在修改了布局或制作流程后再运行：

```bash
npm run world:art
```

烘焙依赖为 Python 3 与 Pillow 11.3.0；项目 TypeScript 使用现有依赖，不额外安装另一套渲染引擎。

## 命名版本

M1 完成封存后，可直接从命名标签复现，不回滚工作区：

```bash
node scripts/buildContinuousWorldPreview.js --ref world/shore-m1-20261109
```

输出为 `node_modules/.cache/continuous-world/versions/world-shore-m1-20261109/game.html`。该入口冻结对应提交的代码、GLSL 和素材；使用自己的浏览器存档命名空间，不偷换当前实验素材、不影响当前实验进度。

历史构建读取对应提交的源文件，旧着色器也从对应版本的 GLSL 重建，不借用当前工作区里生成的 shader。

## 操作

拖动空白区域或 WASD 移动。岸上以左右行走为主；水下保留原有游泳。向浅滩方向移动即可入水，回程向浅坡游去即可落脚上岸。

WASD 是原游戏的轻推输入，按住 Shift 加力；触控拖动幅度越大，推进越强。携带多条鱼返岸时使用充分拖动或 Shift＋上岸方向，不需要上岸按钮。水中推进沿用原装备强度，最大游速单独限制，不能把推进参数误当成速度上限。

靠近地图板、充气架或医疗帐篷后点提示，或按 E 交互。背包、随身听、手电、设置与切屏图标保留；右侧保留原动作盘与绳盘。

侧栏的“保存并原位续接”用于直接检查同一位置、鱼、绳与气量。“总览”是明确的验收镜头，位于游戏外，不替代实际地图板。

“布置三条腰绳”和“布置岸上救援交接”仅用于验收布置，不是游戏传送、捕获或快速回岸能力。

## 验证

```bash
npm run world:check
npm run world:browser
```

第二条需要端口 `60972` 上提供项目文件。测试使用隔离的无头 Chrome，不操纵个人浏览器会话。运行报告和逐帧轨迹写到 `node_modules/.cache/continuous-world/acceptance/`。

命名版本也可直接做同样的真实输入验收：

```bash
JWR_PREVIEW_URL=http://127.0.0.1:60972/node_modules/.cache/continuous-world/versions/world-shore-m1-20261109/game.html npm run world:browser
```

桌面浏览器通过不等于微信真机通过。手机包体、加载、GPU 内存与实际触控仍需 M2 验收。

## 文件职责

`layout.json` 是地形与实体布点定义。`Geometry.ts` 生成共享轮廓、旧洞连接与碰撞；`Runtime.ts` 管理连续介质运动、牵引与实体交接；`WorldSave.ts` 恢复章节对象图。

`RenderWorld.ts` 合成林地、营地、岸坡、水体与逐像素深度光照；`WorldHUD.ts` 只在实体附近提供交互。`bake.py` 烘焙贴图与营地素材。

`Integration.cjs` 构建时对当前实际游戏做带唯一匹配断言的临时接入。源文件形态不兼容时直接报告，不偷偷用旧游戏替代。正式工程源码不被编辑。

## 存档范围

当前实验只使用 `shore-world-review/` 浏览器命名空间和 `continuous_world_v1` 章节 key。命名版本另有独立命名空间。不会改写正式小游戏 v3 档，也不实现跨设备同步。

退出与后台保留实际位置、鱼 ID、绳端引用、背包、救援、探索、已消耗气瓶、气量、体力、BCD 标准气量与氮负荷。后台的绝对计时按暂停锚点重锚定，等待期间不会偷偷消耗眩晕。
