# 林泉营地 M2：场景与稳定性候选

日期：2026-11-09。用户已认可 M1 的大体岸水路线与林地原画意境；本轮重点处理真实游玩中的瞬移、原画放大失真、岸壁到圆岩的割裂，并制作新的人形潜水员样本。

这仍是复用当前真实游戏代码的独立可玩候选，不是另一个逻辑无关的假演示，也没有替换正式手机入口。代码、制作脚本和素材均在项目内；构建时对当前游戏做经过完整类型检查的临时接入。

正式 game.ts、src、原图片和微信配置没有替换。圆岩保底与 M1 完整保留；M2 的代码和对应素材另有独立提交及命名版本。

## 本轮变化

原画按屏幕远景投影，与玩家世界缩放分开，不再把一棵树或几片叶子放大铺满画面。用户喜欢的林冠、留白、斜阳与林地深度在正常游玩镜头中保留，原画母版没有被改写。

岸上到深洞使用同一个连续石灰岩轮廓与材质。原有深洞通路和救援目标保留，岩体不再到固定水平线突然结束、下面接一串球体。接近边缘的厚侧面、岩层、湿润衰减与动态法线共同受光。

人物落脚必须有真实近地距离，负距离不再被当作“就在岸上”。游到岸下方的深洞不会贴回上层地面。救援绳的硬校正也增加每帧位移限制。

岸上起绳保持落脚，低处的绳结通过屈膝蹲身动作处理，不采用水下的全身横转接近。潜水员由同一套分层人形贴图驱动，有面部、肩背、衣料、腕表、气瓶与关节；脚蹼保持尺寸，不用缩小代替穿脱装备。

完整商业、资源转化、跨章节出发、失败恢复、多人联机和装备穿脱流程仍留到后续。本次不做旧存档迁移，M2 测试档直接从新版本开始。

## 运行

在项目根目录执行：

```bash
npm run world:preview
```

输出到已被 Git 忽略的缓存入口 `node_modules/.cache/continuous-world/game.html`。项目 HTTP 预览端口为 `60972`。

普通试玩不需要重新烘焙素材。若修改制作方案，执行：

```bash
npm run world:art
```

依赖现有 TypeScript 及 Python 3 / Pillow 11.3.0，不增加另一套游戏引擎或骨骼运行库。

## 操作

拖动空白区域或 WASD 移动；按住 Shift 或充分拖动加力。沿浅滩移动即可入水，游向浅坡即可落脚返岸，不需要传送式入水或上岸按钮。

靠近地图板、充气架和帐篷后点提示，或按 E 交互。原背包、随身听、手电、切屏图标、动作盘和绳盘保留。

侧栏“保存并原位续接”检查实际位置、鱼、绳与气量；“总览”只改变验收镜头，不替代游戏里的实体地图板。

“三条腰绳”和“救援交接”是明确标注的测试布置，不是游戏捕获、传送或快速返岸能力。不要把主动点击这些布置按钮造成的位置变化当成普通移动。

## 验证

```bash
npm run world:check
npm run world:browser
npm run world:stability
npm run world:stress
```

前一条包括完整 TypeScript 接入与 13 个地图种子的几何回归；后三条使用隔离无头浏览器及实际游戏代码，项目文件须在端口 `60972` 可访问。

稳定性检查专门覆盖岸下深洞：M1 可复现下一帧被贴回地面，M2 同位置正常游动。压力检查覆盖 6 个深度、7,200 帧多方向模拟，另做原生触控岸上系绳、GPU 上下文恢复及反复续接。

命名版本可通过 `JWR_PREVIEW_URL` 指定固定入口，执行同一套 M2 浏览器回归。详细结果见 VALIDATION.md；原始报告位于被忽略的缓存，需保留的摘要与实际效果图位于 review/m2。

## 结构

Geometry.ts 保留营地与浅滩接口；ContourTerrain.ts 将原深洞拓扑与岸坡构造成一体轮廓；TerrainQueries.ts 为原身体、绳、方向射线、手电与路径提供统一查询。

TerrainSurface.ts 使用同一标量字段生成可见岩体，并结合色图、细节法线与边界厚度受太阳、透水光和手电影响；其实际 GPU alpha 另与 CPU 字段做像素验证。

ExpeditionDiver.ts 使用固定人形比例的分层贴图与同一关节驱动。Runtime.ts 负责连续介质运动、实体安置与救援交接；WorldSave.ts 保留新世界对象图。

Integration.cjs 和 ContourIntegration.cjs 仅在候选构建时接入真实游戏，带唯一匹配断言；若当前源码不兼容就报错，不偷偷回退到旧代码。

## 存档与资源边界

M2 使用 `continuous_world_v2` 测试档。旧测试档与夜间对话档无需迁移；没有为清档而删除无关的正式剧情代码。新版本退出位置、绳端、鱼、气量、体力与探索依然精确续接。

正式包的前编译估算仍为 8,252,177 字节，本轮未增加。新场景在设计目录中，不进入正式微信包。正式接入仍需包体治理和微信真机加载、帧率、触控与 GPU 内存验收。

场景图片解码估算、连续几何字段和 GPU 贴图分别统计，不能把压缩文件大小当作运行内存，也不能把桌面浏览器通过当作真机通过。
