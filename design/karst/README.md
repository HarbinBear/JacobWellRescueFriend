# 连续水下溶洞：v1.0.23

本轮直接进入手机版林泉营地连续章节，不是另一套演示渲染器。参考照片的目标不是贴照片，也不是把圆换成随机多边形：洞道围合以完整厚岩为大形，溶蚀凹口、矿物叠层及由顶壁生长的尖端只在局部聚集；保留大片深黑、不可见的水域。岸上营地、潜水员和海上连接结构不重做。

## 内容与数据

- `src/world/KarstTerrain.ts` 在现有种子迷宫拓扑和岸水接缝上生成连续的 12px 密度场。三频变形、沉积侵蚀与钙华簇用无状态整数哈希，从主种子派生；不改变 `generateMazeMap` 的 PRNG 序列、格子、墙句柄顺序或存档格式。每次入场生成一次，退出释放 CPU/GPU 表面；同种子与同版本生成一致。
- 窄通道、分岔格中心、泉井和救援目标保持身体净空，大洞室内部允许长沉积，断开的沉积片清理掉。Marching squares 从**同一个标量场**产生真实轮廓。碰撞、手电遮挡、绳盘找墙、鱼的近障判定和锚点查询共享它，不允许画得见却碰不到的装饰石。
- `scripts/bakeKarstMaterials.py` 离线生成四块矿物材质：溶蚀石灰岩、流石、层状断面与多孔钙华。每块高度、法线和 AO 同源，色图只保存矿物色差、铁褐、蜡黄、象牙与表面细碎起伏，不把固定光源烘焙成图片。1024² atlas 和 8px gutter 避免缩放时的材质缝，当前贴图无须运行时重烘焙。
- `src/render/RenderKarst.ts` 只对摄像机可见部分画一个表面 pass；由已有主手电射线插值遮挡，坡度与同源细法线计算受光，凹槽遮挡、三处真实碰壁反射及水的波段吸收给近暖、稍远青绿、再远近黑的连续衰减。保留原 WebGL 体积光/遮罩双 canvas 的 iOS 修复约定，溶洞只在本章节启用新分支。
- 不新增能抢走前景语义的独立后景岩壁。水域只保留低对比透射与局部散射，未在本轮制作照片背景或跨洞室远景视差。

## 运行及评审

- `npm run world:preview` 构建当前手机版 `game.ts + src/` 的连续章节，入口 `node_modules/.cache/continuous-gameplay/game.html`。
- `npm run karst:preview` 使用**同一套手机版源码和正式材质**，另加只在评审包里的三处观察位置、转灯、开关灯和单色检查按钮，入口 `node_modules/.cache/karst-review/live/game.html`。这些按钮与测试布置都不会进入微信包体。
- `npm run karst:check` 检查类型、5 个种子指纹、人物真实半径导航、碰撞/射线/锚点一致性和8MB静态包体；`npm run karst:browser` 检查正式浏览器游戏多个洞室、转灯、GPU轮廓对位、横竖屏、上下文丢失、缺失 `performance`、卸载与存档续接。可选 `node_modules/.cache/cave-sculpt-python/bin/python scripts/checkKarstMaterials.py` 检查法线高度一致；重新烘焙需要 `design/karst/requirements.txt`，普通运行不依赖 Python。
- 主流程浏览器回归另跑 `npm run world:entry`、`npm run world:stability`、`npm run world:regression` 和 `npm run rope:check`。上述截图和报告都写到被 Git 忽略的 `node_modules/.cache/karst-review/`，不作为正式打包资源。

## 已检查与边界

- 5 个种子均能重建相同的密度场、沉积、轮廓；5 张图从泉井到救援目标均通过真实18px人物半径导航。深洞6个点 7200 帧的连续移动没有穿岩、失控跳跃或异常。浏览器中转灯改变的世界像素样本约4.7万处，竖屏与横屏画布/岩壁采样均无物理-GPU覆盖漏点；WebGL context 恢复与退出资源释放通过。
- 当前文件静态候选约7.65MiB，留约355KiB（含至少128KiB储备）。**这不是微信开发者工具编译后的权威包大小**。单独纹理解码约8MiB，动态岩面 GPU 目标+场约13–15MiB，另有原项目两套灯光缓存；低档通过质量预设减少岩面分辨率。桌面 Chrome 中档转灯动态200帧约16.67ms（显示器 vsync），**不能据此承诺手机 60FPS**。微信手机上的 shader 兼容、GPU 内存峰值、编译包体和实际帧率仍待真机测量。
- 本轮不是完全3D，也没有多层自遮挡、随镜头显露背面、视差模糊后景或严格的水下辐射传输方程；所做的是兼容微信小游戏预算的2.5D高度/法线加有限遮挡与 Beer-Lambert 色散近似。尚需真人审美验收及进一步打磨洞室大形，不能凭自动化测试宣称最终美术定稿。
- 保留先前认可的 `design/cave-room/` 研究、试跑、原贴图与 Git 历史。`ToDo.md` 是用户当前未完成的其他修改，本轮没有编辑或提交它。
