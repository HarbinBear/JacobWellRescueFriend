# 溶洞可选迭代

用户2026-11-10的新反馈要求材质服务于尖端/折面、去掉重复/拼接、洞室生成语法不同、恢复bounce，并保留中间成果。原实装提交5159f01已添加命名标签 `cave/karst-v01-integrated`，没有覆盖或替换原矿物图片。

## E01：造型绑定材质与反射

- 基础密度场、洞穴通路、墙句柄和种子指纹保持V01。新增表面根据实际沉积轴线和宽度形成柱面映射，尖端越窄、纹理越向生长轴收束；同一截面决定厚度、宏观法线与细节取向。
- 平铺采样改为三角随机连续组合。不把整幅流石、水平层纹混在普通岩面上。首次实装截图暴露根部UV跳变导致密集刷状伪影，已修正为岩面根部坐标连续，并减弱原流石的周期横向微法线；原色图保留。
- V01的水体溶洞分支早返回，绕过已上传旧VPL。E01增加最多6处实际击壁、法线与矿物色驱动的反射源，同一结果用于岩壁、水体散射和遮罩；每源64方向二次遮挡，照不到的障碍背面不铺亮色背景。
- `CONFIG.karst.surfaceMode` 或GM「溶洞/表面版本」可以即时选择 `baseline` 原V01或 `sculpted` E01，不改变通路。`bounceStrength=0` 可关闭E01反射单独比较。
- 验证：5个种子旧指纹与真实半径路径不变；实际游戏浏览器的GPU覆盖、转灯、竖横屏、context恢复、无performance与退出释放通过。未做微信真机性能或主观美术批准。

## E02：四种洞室地质语法

- 沿用E01同源材质/反射，但保留E01完整独立shader `karstCoherentFrag.glsl`，E02自有shader支持三平面侧面取样；不把新材质改动偷偷影响E01。四种洞室并非仅换皮：流石垂幕成组长滴、倾斜断裂的偏压断面、多孔钙华的团簇崖面、巨岩低拱的偏心厚岩。每类使用不同的空腔公式、侵蚀频段、沉积截面、法线起伏、矿物色向及灯下侧面表现。
- 按实际迷宫连通区域寻找洞室核心，确定性种子为洞室选类别；窄道、分岔及任务目标通过连续的34px身体净空管保护，密度场依然是碰撞、绳索、遮挡和GPU表面同一个来源。新章节可通过GM选择几何版；存档额外记住选定生成版，旧存档缺少此字段时始终恢复旧几何，避免载入后角色卡进不同洞形。
- 真实游戏评审布置可在同机位比较V01/E01/E02，四种洞室另有单色体积图及bounce开关图。E02截图曾出现矩形保护切面、部分很黑的机位、矿物过于雷同：改用连续净空管、圆角断面、实拍侧面和各类矿物色后保存。仅凭数值验证不宣称美术已经达到参考照片水平，尤其断裂洞室的英雄机位仍需人工检查；不默认选E02取代现有游戏版。
- `JWR_KARST_GENERATION=chambers node scripts/checkKarstTerrain.js`对5种子检验真实18px半径导航、确定性、碰撞/射线/墙索引；同一实装评审入口的四类画面与GPU覆盖/反射开关检查通过。E02手机GPU帧率和官方编译体积仍待真机验证。此阶段后如试风格化，必须是独立shader与独立提交，不能覆盖E02，更不能覆盖E01或V01。
