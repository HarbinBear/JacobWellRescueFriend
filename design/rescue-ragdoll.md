# 敲晕与布娃娃救援

被救者保持蹦迪人设。救援改为「短蓄力敲晕 → 松手 → 再按住绑绳 → 拖回洞口」。

- 靠近后按住角色 0.55 秒敲晕，提前松手或离开接触范围取消。敲晕和绑绳期间不固定玩家，惯性、移动操作、呼吸浮力和 BCD 浮力照常生效；玩家需要自行配平，稳定保持接触距离再完成长按。这是操作考核点，不另加节拍判定。
- 敲晕后停止跳舞，出现短促的拳击动作、星星、原创橡皮敲击声和下降哨音。音乐从此回到平静返程段，不再因角色入镜重新升起。
- 松手后再次按住角色 0.8 秒绑绳。同一次长按不会连着完成两步。
- 台词：「……先暂停一下。」「这回不蹦了。」绑绳确认：「好，打包带走。」
- 身体由松弛绳索、弹性拉力和水阻带动，不主动向玩家游动。头、双臂、双腿共九个角度关节独立受惯性、阻尼和弱重力影响，转弯滞后、急停甩动、静止后收敛。
- 身体检查岩石碰撞，绳长修正检查移动路径；手脚采用固定骨长的关节姿态，不单独做岩石碰撞。这是便于小游戏运行的轻量近似。
- 敲晕、关节速度和短暂反馈不写入存档，每次下潜清零。案件探索、绳索与图鉴进度沿用原逻辑。

运行 `npm run maze:check` 检查两阶段输入、取消、重复下潜、物理收敛、惯性与碰撞；`npm run visuals:check` 检查显示；`node scripts/checkAdaptiveGameplay.js` 检查音乐切换。`npm run game:preview` 重新生成实际游戏预览。
