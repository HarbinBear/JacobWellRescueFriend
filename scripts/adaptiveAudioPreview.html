Signal Below VI

电子弦乐主题，从深处的微光到发现目标时的激动。
五层主要音型密度：30 → 60 → 120 → 240 → 1200 次/分钟。第五层为有音高的十连音疾奏。

先听：发现后的和声重写

旧版与新版发现主题：0:00旧版小调、0:16新版大调。保持相同主音量，比较和声与旋律落点。

三状态底轨：0:00 寻找 → 0:16 发现 → 0:32 返程。寻找保留小调悬念，发现改写为大调和声、同步伴奏与更舒展的长句，返程保留落定感；开头动机仍相互呼应。

完整救援过程：0:00 寻找 → 0:08 四级推进 → 0:14 过门 → 0:16 乐句开头、温暖主题与第五层展开 → 0:24 绑好、确认音与返程。

死亡反馈：清楚的duang起音，再沉入低频与远处共鸣。

比较音乐 A / B / C 与事件音

A/B/C都采用同主题三态。可以先听48秒色彩对比、40秒完整救援，再分别比较旋律和死亡落音。

实时切档与事件试听

人物入镜后申请高潮，等待下一组两小节乐句的开头（最多约4秒），前一小节有滚奏过门。发现后的和声、低音与琶音共同转暖。
